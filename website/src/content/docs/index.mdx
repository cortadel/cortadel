## What is Cortadel?

Cortadel gives an AI agent a durable, queryable memory that survives across sessions — a
**bi-temporal knowledge graph**, not a vector blob. It extracts facts, links entities, resolves
contradictions, reconciles duplicate entities, and returns the right context with **no LLM call on
the read path**.

- **Two ways in** — a typed REST API and a Model Context Protocol (MCP) endpoint.
- **One container** — API, MCP, and dashboard in a single .NET 10 process over FalkorDB or Memgraph.
- **Yours to run** — self-hosted; the SDK and these docs are Apache-2.0, the engine is a commercial
  product. See [cortadel.ai](https://cortadel.ai).
