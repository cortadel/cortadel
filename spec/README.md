# API contract

`openapi.json` describes the supported public REST surface of the Cortadel
server. It is generated from the server's controllers, not written by hand, and
it is the single input from which the .NET, TypeScript and Python SDKs are
generated with [Kiota](https://learn.microsoft.com/openapi/kiota/overview).

Do not edit this file. It is regenerated server-side and synced here; a CI check
fails if generated SDK code no longer matches it.
